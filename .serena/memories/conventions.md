# Conventions

- Reply language and commit messages must be Chinese; user-facing replies start with `sbw：`.
- Before repository changes, state requirement understanding and wait for user confirmation.
- Markdown style: clear headings, short paragraphs, actionable bullets, preserve numeric directory prefixes and Chinese domain names.
- Project folder naming uses ID plus title, e.g. `P001-CS基础重建`; dated journal files follow existing patterns such as `2026-W17.md`.
- Long-term/life-stage planning belongs in `guideline/`, not `0-Projects/`; `0-Projects/` is for concrete executable projects.
- For Trilium sync notes, source path/sync metadata is currently generated by `scripts/sync_to_trilium.py`, not Trilium itself.
