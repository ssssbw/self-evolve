# 第一个五年计划

> 周期：2025-03-24 \~ 2030-03-24\

## 目录作用

本目录存放第一个五年相关的规划和阶段作战表。这里承接 `guideline/二十年总纲.md`，比具体项目更上层，但比二十年总纲更可执行。

适合放在这里的内容：

- 第一个五年的总计划。
- 当前年度或阶段作战表。
- 阶段复盘和年度检查。

不适合放在这里的内容：

- 每周复盘，放入 `4-Journal/weekly/`。
- 具体学习项目，放入 `0-Projects/`。
- 技术、理财、认知的长期资料，放入 `1-Areas/` 或 `2-Resources/`。
