# P004 — 第二份工作准备

> 开始日期：2026-07-24  
> 项目状态：进行中  
> 项目性质：长期滚动更新的职业资产项目，不设置固定结束日期。

## 项目目标

为第二份工作做系统准备，主线转向 AI 应用工程师 / AI 全栈方向，副线保留 Flutter + AI 移动端应用优势。通过当前公司的用户反馈评估系统项目，沉淀可写进简历、可用于面试表达、可迁移到个人作品的 AI 应用工程经验。

## 背景判断

- 当前税前月薪约 8500，且公司已有大小周和额外加班压力。
- 继续被动加班会挤压跳槽准备时间，长期投入产出比偏低。
- 第二份工作不应只以 Flutter 为边界，应争取靠近 AI 应用、全栈交付和业务智能化方向。
- 当前公司安排的用户反馈评估系统，刚好可以作为进入 AI 应用工程方向的现实踏板。

## 方向定位

### 主线：AI 应用工程师 / AI 全栈

目标能力：

- 能把业务数据接入大模型分析链路。
- 能设计 Prompt、结构化输出、分类体系和评估方法。
- 能完成前后端闭环交付，包括接口、报表、权限、日志和异常处理。
- 能说明 AI 应用的成本、稳定性、准确率和业务价值。

### 副线：Flutter + AI 移动端应用

目标能力：

- 保留移动端交付优势，避免直接丢弃已有经验。
- 能将 AI 能力接入 App 场景，例如智能客服、反馈分析、个人助手、内容总结和业务辅助工具。
- 在求职表达中形成“客户端工程能力 + AI 应用落地能力”的组合标签。

## 现实项目牵引机制

AI 全栈能力金字塔是长期地图，当前公司用户反馈评估系统是现实战场，Self-Evolve AI 助手是长期公开作品。执行时不机械等待 L1 到 L7 全部学完，而是采用“公司项目牵引 + 长期作品迁移 + 缺口补课”的方式。

原则：

- 公司项目优先：凡是当前项目马上要用到的能力，优先学习和实践。
- 长期作品迁移：公司项目中学到的通用能力，后续迁移到 Self-Evolve AI 助手，不能混用公司数据。
- 金字塔补位：公司项目或长期作品暴露出哪个能力缺口，就回到对应层补最小必要知识。
- 不追求完整学习：只学当前项目能用上的最小闭环，避免因路线过大拖慢现实交付。
- 产出必须沉淀：公司项目中出现的问题、方案和结果，要回填到职业资产、challenge 和面试表达。
- 手写优先：challenge 的核心设计、代码、复盘和表达必须自己完成；AI 只能用于解释、提示、review 和追问，不能直接生成最终答案照抄。

当前公司项目对应金字塔：

| 公司项目任务 | 对应层级 | 学习重点 |
| ------------ | -------- | -------- |
| 聊天记录字段理解、清洗和脱敏 | L1 / L4 | 数据结构、隐私边界、输入规范 |
| 调用大模型分析对话 | L3 | Prompt、Structured Output、超时重试 |
| 输出产品、销售、服务等分类结果 | L3 / L4 | 分类体系、JSON schema、多标签设计 |
| 报表展示和筛选 | L2 | API、前端报表、分页筛选 |
| 判断模型分析是否准确 | L5 | 抽检、误判记录、评估指标 |
| 控制成本和失败 | L5 | Token、日志、降级、重试 |
| 整理成简历项目 | L7 | 项目故事、量化结果、技术取舍 |

执行顺序：

1. 先把公司项目拆成“输入、分析、输出、评估、报表”五段。
2. 每段只补对应金字塔中的最小知识。
3. 每周至少记录 1 条项目证据。
4. 每完成一个关键能力点，去 `5-Playground/P004-第二份工作准备/` 完成对应 homework、knowledge test 或 challenge。
5. 周日复盘时检查：本周工作是否产生了可写进简历的证据。

## 验收与 challenge 机制

P004 不以“看完教程”作为完成标准。每个关键能力点至少需要一个 challenge 证明已经达到可用水平。

验收标准：

- 20%：看过课程，理解基本概念。
- 40%：能跟着教程实现。
- 60%：能脱离教程独立实现。
- 80%：能集成进项目并部署或跑通完整流程。
- 100%：能讲原理、做取舍、测指标、解决实际问题。

只有达到 80% 才算点亮，达到 100% 才算面试级能力。

challenge 保存位置：

```text
5-Playground/P004-第二份工作准备/
```

每个 challenge 必须包含：

- 目标：验证哪一层能力。
- 任务：要完成什么产出。
- 验收：用什么证据判断完成。
- 手写记录：记录自己查了哪些资料、怎么设计、第一版怎么实现。
- AI 使用边界：记录 AI 参与了什么，只允许解释、提示、review、追问，不允许生成最终答案照抄。
- 复盘：做完后记录问题、方案、结果和可写进简历的表达。
