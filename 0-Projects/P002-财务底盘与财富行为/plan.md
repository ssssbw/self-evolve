# P002 — 财务底盘与财富行为

## 项目目标

先建立可持续更新的个人财务底盘，再通过《金钱心理学》理解金钱决策中的行为、风险与长期主义。

## 范围与边界

- 第一阶段：记录资产、负债、现金流、储蓄率和备用金缺口。
- 第二阶段：阅读《金钱心理学》，形成消费、储蓄和风险原则的第一版。
- 不以短期收益检验学习效果，不把阅读结论直接变成买卖指令。

## 里程碑

- [ ] 完成一份可按月更新的资产、负债与现金流记录。
- [ ] 写明备用金目标及达到目标前的风险资产原则。
- [ ] 完成《金钱心理学》的阶段讨论与实践记录。
- [ ] 找出至少 3 个个人金钱行为误区，并为每个写出一条纠偏规则。

## 通关条件

- 能准确说明当前净资产、月储蓄额和备用金缺口。
- 能解释“赚到钱”和“留住钱”需要的能力为何不同。
- 已形成个人消费、储蓄和风险原则的第一版。
