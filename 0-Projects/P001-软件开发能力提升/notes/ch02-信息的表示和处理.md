# 第 2 章 — 信息的表示和处理

## 本章概览

本章讲计算机如何用二进制表示数字。核心是三种编码：无符号整数（unsigned）、有符号整数（补码 two's complement）、浮点数（IEEE 754）。理解这些，你才能明白为什么整数会溢出、为什么 0.1 + 0.2 != 0.3。

## 核心概念

### 概念 1：无符号编码（Unsigned）
- 一句话定义：用固定长度的二进制直接表示非负整数，每位都是权重。
- 为什么重要：地址、大小、计数都使用无符号数。
- 关键公式：B2U(w) = Σ(b_i × 2^i)，范围 [0, 2^w - 1]

### 概念 2：补码编码（Two's Complement）
- 一句话定义：最高位是符号位（1 表示负数），负数用"取反加一"表示。
- 为什么重要：几乎所有编程语言的有符号整数都用补码。理解补码才能理解溢出。
- 关键公式：B2T(w) = -b_{w-1} × 2^{w-1} + Σ(b_i × 2^i)，范围 [-2^{w-1}, 2^{w-1} - 1]
- 关键特性：TMin = -2^{w-1}，TMax = 2^{w-1} - 1，注意 TMin 的绝对值比 TMax 大 1

### 概念 3：整数运算与溢出
- 一句话定义：固定长度的整数运算结果可能超出表示范围，超出部分被截断。
- 为什么重要：溢出是无数安全漏洞和 bug 的根源。
- 关键点：
  - 无符号加法溢出：结果对 2^w 取模
  - 补码加法溢出：正溢出变负数，负溢出变正数
  - 乘法溢出：结果截断为 w 位
  - x * 2^k 等价于 x << k（编译器优化利用这个）

### 概念 4：IEEE 754 浮点数
- 一句话定义：用"符号位 + 指数 + 尾数"三个字段表示实数，类似科学计数法。
- 为什么重要：解释了浮点精度问题的根源。
- 关键结构（单精度 32 位）：
  - 1 位符号（s）
  - 8 位指数（exp）
  - 23 位尾数（frac）
  - 值 = (-1)^s × 1.frac × 2^{exp-127}（规格化数）
- 关键特性：
  - 精度有限（float 约 7 位有效数字，double 约 15 位）
  - 分布不均匀：越靠近 0 越密集
  - 特殊值：+0/-0、+∞/-∞、NaN

### 概念 5：位级运算
- 一句话定义：与（&）、或（|）、非（~）、异或（^）直接操作二进制位。
- 为什么重要：在底层编程、加密算法、图形处理中大量使用。
- 关键技巧：
  - x ^ x = 0（异或自身清零）
  - x & 0xFF = 取最低字节（掩码）
  - 掩码操作：用 & 提取位，用 | 设置位，用 ^ 翻转位

### 概念 6：扩展与截断
- 一句话定义：将一个 w 位的数转换为更多或更少位数。
- 关键规则：
  - 无符号扩展：零扩展（高位补 0）
  - 补码扩展：符号扩展（高位补符号位）
  - 截断：直接丢弃高位，相当于对 2^k 取模

## 难点预警

- **补码的理解**：不要死记公式，用"取反加一"手动算几个例子建立直觉
- **浮点数的精度**：亲手算一下 0.1 的二进制表示，你会理解为什么它是无限循环
- **溢出检测**：理解判断溢出不需要知道符号位，只需要看两个输入和输出的符号关系

## 必做练习

- Data Lab（CSAPP 官网下载）—— 用位操作实现各种功能，不许用算术运算符
- 手算：用 8 位补码表示 -1, -128, 127, -5
- 手算：0.1 的单精度 IEEE 754 表示（理解为什么是近似值）

## 与 Flutter/Dart 的关联

- **Dart 没有 unsigned int**：Dart 只有 `int`（64 位有符号）。但理解 unsigned 对你读其他语言代码和底层协议很重要（比如 TCP 序列号是 32 位 unsigned）。
- **浮点精度**：Flutter 中用 `double` 处理金额时务必小心。0.1 + 0.2 在 Dart 里也不等于 0.3。涉及货币计算时，用整数（分）或 `decimal` 包。
- **位运算在 Dart 中**：Dart 支持 `&`, `|`, `^`, `~`, `<<`, `>>`, `>>>`。在处理颜色值（ARGB）、权限掩码、协议解析时会用到。
- **int 在不同平台的表现**：Dart VM 上 int 是 64 位，但编译到 JS（Flutter Web）后变成 JavaScript number，行为不同！

## 关键术语对照

| 英文 | 中文 | 一句话解释 |
|------|------|-----------|
| two's complement | 补码 | 用取反加一表示负数的编码方式 |
| unsigned | 无符号 | 只表示非负整数 |
| overflow | 溢出 | 运算结果超出表示范围 |
| sign bit | 符号位 | 最高位，0 正 1 负 |
| exponent | 指数 | 浮点数中的阶码部分 |
| mantissa/significand | 尾数 | 浮点数中的有效数字部分 |
| NaN | 非数值 | Not a Number，无效运算结果 |
| rounding | 舍入 | 将精确值映射到可表示的浮点数 |
| zero extension | 零扩展 | 高位补 0 来扩展位数 |
| sign extension | 符号扩展 | 高位补符号位来扩展位数 |
| mask | 掩码 | 用于提取或设置特定位的值 |
