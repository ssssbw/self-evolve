# 第 7 章 — 链接

## 本章概览

链接是将多个代码模块合并为一个可执行文件的过程。理解链接，你才能理解"undefined reference""duplicate symbol"等编译错误的根源，以及动态库、静态库的区别。

## 核心概念

### 概念 1：编译器驱动程序
- 一句话定义：gcc 等"编译器"实际上是一个协调器，依次调用预处理器、编译器、汇编器、链接器。
- 为什么重要：理解整个工具链，才能在出错时定位是哪个环节出了问题。

### 概念 2：静态链接
- 一句话定义：链接器将多个可重定位目标文件合并为一个可执行文件，解析符号引用。
- 关键步骤：
  1. 符号解析：将每个符号引用绑定到一个符号定义
  2. 重定位：将符号引用替换为实际地址
- 关键规则：强符号（函数和已初始化的全局变量）只能定义一次，弱符号（未初始化的全局变量）可以多次定义但取一个。

### 概念 3：目标文件格式（ELF）
- 一句话定义：Linux 下可重定位文件、可执行文件、共享库的标准格式。
- 关键节（Sections）：
  - .text：已编译的机器码
  - .data：已初始化的全局/静态变量
  - .bss：未初始化的全局/静态变量（不占文件空间，运行时清零）
  - .symtab：符号表
  - .rel.text / .rel.data：需要重定位的位置

### 概念 4：符号解析
- 一句话定义：将每个符号引用关联到唯一的符号定义。
- 关键问题：
  - 多重定义：同名全局变量在多个文件中定义 → 链接错误
  - 未定义引用：引用了一个不存在的符号 → "undefined reference"
  - 静态变量（static）：只在当前文件可见，不参与全局符号解析

### 概念 5：重定位
- 一句话定义：链接器为每个符号分配运行时地址，修改代码中对这些符号的引用。
- 关键步骤：
  1. 将所有相同类型的节合并（所有 .text 合并为一个 .text）
  2. 为每个节分配运行时地址
  3. 修改每个重定位条目（绝对地址或 PC 相对地址）

### 概念 6：动态链接与共享库
- 一句话定义：程序运行时才加载和链接的库（.so / .dll），多个进程可共享同一份库代码。
- 为什么重要：节省磁盘空间和内存，方便库更新。
- 关键技术：
  - 位置无关代码（PIC, Position-Independent Code）：代码可以加载到任意地址运行
  - GOT（全局偏移表）：间接引用全局变量
  - PLT（过程链接表）：延迟绑定函数地址（第一次调用时才解析）
  - 延迟绑定（Lazy Binding）：函数第一次被调用时才解析地址，加速启动

## 难点预警

- ELF 格式的细节很多，不需要全记——重点理解 .text/.data/.bss 和符号表
- 重定位的计算过程需要结合具体的汇编代码理解，建议用 `objdump -r` 查看
- PIC 和 PLT 的机制比较抽象，画图有助于理解

## 必做练习

- 用 `readelf` 或 `objdump` 查看一个真实可执行文件的节和符号表
- 故意制造一个"多重定义"和一个"未定义引用"错误，观察编译器的输出
- 用 `nm` 查看静态库和动态库的符号差异

## 与 Flutter/Dart 的关联

- **Flutter 的构建过程**：Flutter 构建涉及 Dart 代码编译为 snapshot/kernel，然后与 Flutter Engine（C++ 动态库）链接。理解链接过程有助于排查构建错误。
- **插件系统**：Flutter 的 plugin 系统本质上就是一个动态链接机制——每个 platform plugin 是一个共享库（Android 的 .aar/.so，iOS 的 .framework），在运行时通过 FFI 或消息通道链接。
- **Dart 的编译产物**：Dart AOT 编译产物（app.so）本质上就是一个共享库，包含编译后的机器码和元数据。
- **热重载的原理**：开发时 Dart VM 动态加载新的 kernel 文件并重新链接，这就是为什么热重载能瞬间生效——不需要重新编译和链接整个应用。

## 关键术语对照

| 英文 | 中文 | 一句话解释 |
|------|------|-----------|
| linker | 链接器 | 合并目标文件并解析符号 |
| object file | 目标文件 | 编译器的输出，包含机器码和元数据 |
| ELF | 可执行与可链接格式 | Linux 目标文件的标准格式 |
| symbol | 符号 | 函数和全局变量的名称 |
| relocation | 重定位 | 为符号分配实际地址 |
| static linking | 静态链接 | 编译时将库嵌入可执行文件 |
| dynamic linking | 动态链接 | 运行时加载共享库 |
| shared library | 共享库 | 运行时加载的库（.so / .dll） |
| PIC | 位置无关代码 | 可以加载到任意地址运行的代码 |
| GOT | 全局偏移表 | 间接引用全局变量的表 |
| PLT | 过程链接表 | 延迟绑定函数调用的表 |
