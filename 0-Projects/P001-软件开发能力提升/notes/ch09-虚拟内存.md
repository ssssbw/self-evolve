# 第 9 章 — 虚拟内存

## 本章概览

虚拟内存是操作系统最精妙的发明之一：让每个进程以为自己独占了整个内存空间，实际物理内存可能远小于进程看到的地址空间。本章是 CSAPP 第三难的章节，但理解后你会发现它贯穿了所有后续内容。

## 核心概念

### 概念 1：虚拟地址空间
- 一句话定义：每个进程看到的独立、连续的地址空间（32 位进程看到 4GB，64 位进程看到 2^48 字节）。
- 为什么重要：虚拟内存让程序不需要关心物理内存布局，简化了编程模型。
- 关键特性：
  - 每个进程有独立的虚拟地址空间
  - 虚拟地址通过页表映射到物理地址
  - 不是所有虚拟地址都有对应的物理页——按需分配

### 概念 2：页表与地址翻译
- 一句话定义：页表是虚拟页到物理页的映射表，由操作系统维护，MMU（内存管理单元）硬件加速查找。
- 关键过程：
  1. CPU 发出虚拟地址
  2. 虚拟地址分为虚拟页号（VPN）+ 页内偏移（VPO）
  3. 用 VPN 查页表，得到物理页号（PPN）
  4. 物理地址 = PPN + VPO
- 关键标志位：
  - 有效位（Valid）：该页是否有对应的物理页
  - 脏位（Dirty）：该页是否被修改过
  - 引用位（Reference）：该页是否被访问过（用于页面替换算法）

### 概念 3：TLB（Translation Lookaside Buffer）
- 一句话定义：页表的高速缓存，缓存最近使用的虚拟页到物理页的映射。
- 为什么重要：没有 TLB，每次内存访问都需要额外访问一次页表（也在内存里），性能减半。
- 关键特性：
  - 通常在全相联或高关联度的缓存中实现
  - TLB 缺失时需要遍历页表（硬件或软件遍历）
  - TLB 是虚拟内存性能的关键——大多数时候 TLB 命中，地址翻译极快

### 概念 4：多级页表
- 一句话定义：用树形结构组织页表，只在需要时才分配页表页，节省内存。
- 为什么重要：64 位地址空间如果用单级页表，页表本身就需要 TB 级内存。多级页表只分配实际使用的部分。
- 关键思想：大部分虚拟地址空间是未使用的（空洞），不需要为这些空洞分配页表。

### 概念 5：缺页处理（Page Fault）
- 一句话定义：CPU 访问的虚拟页不在物理内存中，触发异常，操作系统从磁盘加载该页。
- 关键过程：
  1. CPU 访问虚拟地址，页表有效位为 0
  2. 触发缺页异常（Fault）
  3. OS 在磁盘上找到该页，加载到物理内存
  4. 更新页表映射
  5. 重新执行导致缺页的指令
- 页面替换策略：物理内存满了需要驱逐一个页面（LRU、FIFO、Clock 等）

### 概念 6：内存映射（mmap）
- 一句话定义：将文件或设备映射到虚拟内存空间，通过内存操作读写文件。
- 为什么重要：高效的文件 I/O 方式，避免了 read/write 的内核-用户空间数据拷贝。
- 共享内存：两个进程 mmap 同一个文件，就实现了共享内存通信。

## 难点预警

**这是 CSAPP 中第三难的章节。** 具体难点：
- 地址翻译的计算需要手动推导，结合页表结构和 TLB
- 多级页表的层级关系容易搞混
- 缺页处理是一个"异常 → OS 处理 → 恢复执行"的完整循环

**攻克建议：**
- 画一张图：虚拟地址 → TLB → 页表 → 物理地址的完整路径
- 手动计算一个具体的地址翻译例子
- 理解"虚拟内存 = 按需调页 + 页表 + TLB"三件套

## 与 Flutter/Dart 的关联

- **Dart 的 Isolate 和内存**：每个 Isolate 有自己的堆（Heap），本质上是独立的虚拟地址空间。Isolate 之间不能直接共享对象，就像进程之间不能直接共享虚拟内存页。
- **Dart VM 的内存管理**：Dart VM 的分代 GC（新生代/老生代）利用了局部性原理——新创建的对象在新生代（一小块内存），GC 只扫描新生代大部分时候就够了，类似只扫描活跃的虚拟页。
- **Flutter 的图片内存**：大图片的解码内存是通过操作系统分配的。理解虚拟内存和按需调页，有助于理解为什么加载一张 100MB 的图片不会立刻占用 100MB 物理内存。
- **内存泄漏的排查**：Dart DevTools 中的 Heap Snapshot 本质上是在遍历 Dart 对象的虚拟地址空间。理解内存分配和回收的底层原理，有助于排查内存泄漏。

## 关键术语对照

| 英文 | 中文 | 一句话解释 |
|------|------|-----------|
| virtual address | 虚拟地址 | 进程看到的地址 |
| physical address | 物理地址 | 内存芯片上的实际地址 |
| page | 页 | 虚拟内存管理的最小单位（通常 4KB） |
| page table | 页表 | 虚拟页到物理页的映射表 |
| MMU | 内存管理单元 | 硬件，加速地址翻译 |
| TLB | TLB | 页表的高速缓存 |
| page fault | 缺页 | 访问的页不在物理内存中 |
| demand paging | 按需调页 | 只在实际访问时才加载页面 |
| mmap | 内存映射 | 将文件映射到虚拟内存 |
| swap | 交换空间 | 磁盘上用于存放被驱逐页面的区域 |
| page replacement | 页面替换 | 物理内存满时选择驱逐哪个页面 |
