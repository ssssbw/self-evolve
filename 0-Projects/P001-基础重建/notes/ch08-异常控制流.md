# 第 8 章 — 异常控制流

## 本章概览

从最底层的硬件异常（中断、陷阱、故障、终止）到操作系统层面的进程和信号，再到 C 语言中的非本地跳转（setjmp/longjmp）。本章是理解"程序如何与操作系统交互"的关键章节。

## 核心概念

### 概念 1：异常（Exception）
- 一句话定义：CPU 对系统状态变化的响应，将控制权从应用程序转移到操作系统内核。
- 为什么重要：异常是操作系统实现进程、虚拟内存、I/O 的基础机制。
- 关键分类：
  - 中断（Interrupt）：来自外部 I/O 设备的信号，异步发生。如键盘输入、定时器。
  - 陷阱（Trap）：有意为之的异常，用于系统调用。执行 syscall 指令触发。
  - 故障（Fault）：可能可恢复的错误。如缺页异常（Page Fault）——页不在内存，从磁盘加载后可以继续执行。
  - 终止（Abort）：不可恢复的致命错误。如硬件故障。

### 概念 2：进程
- 一句话定义：一个执行中程序的实例，拥有独立的逻辑控制流和私有地址空间。
- 为什么重要：进程是操作系统最重要的抽象。你运行的每个 Flutter app 都是一个进程。
- 关键特性：
  - 逻辑控制流：程序看起来独占 CPU（实际是时间片轮转）
  - 私有地址空间：程序看起来独占内存（实际是虚拟内存）
  - 上下文切换：OS 保存当前进程状态，恢复另一个进程的状态

### 概念 3：系统调用
- 一句话定义：程序通过 syscall 指令主动请求内核服务（如读写文件、创建进程）。
- 为什么重要：所有 I/O、进程管理、网络通信最终都通过系统调用完成。
- 关键系统调用：
  - fork()：创建子进程（子进程是父进程的副本）
  - execve()：加载并运行新程序
  - waitpid()：等待子进程结束
  - exit()：终止当前进程
  - read()/write()：读写文件

### 概念 4：进程的生命周期
- 一句话定义：进程从创建到终止的状态转换。
- 关键状态：运行 → 停止 → 终止
- 关键事件：
  - fork 创建新进程
  - 调度器将进程从运行切换为就绪（或反之）
  - 信号导致进程停止
  - exit 或收到 SIGKILL 导致终止
  - 僵尸进程（Zombie）：子进程已终止但父进程还没 wait——占用系统资源

### 概念 5：信号（Signal）
- 一句话定义：操作系统向进程发送的异步通知，进程可以忽略、捕获或执行默认处理。
- 为什么重要：信号是 Unix 系统中进程间通信和异常处理的核心机制。
- 关键信号：
  - SIGINT（2）：Ctrl+C 中断
  - SIGKILL（9）：强制终止（不可捕获）
  - SIGSEGV（11）：段错误（非法内存访问）
  - SIGTERM（15）：请求终止（可捕获）
  - SIGCHLD：子进程状态变化
- 信号处理的关键问题：
  - 信号可能被阻塞（block）
  - 同类信号不排队（多个 SIGINT 可能只处理一次）
  - 信号处理函数中只能调用异步安全函数

### 概念 6：非本地跳转
- 一句话定义：setjmp/longjmp 允许从一个函数直接跳回另一个函数（不经过正常的调用/返回栈），类似"超级 goto"。
- 为什么重要：用于实现异常处理机制（C 语言没有 try/catch，用这个代替）。

## 难点预警

- fork 的"调用一次返回两次"（父进程返回子进程 PID，子进程返回 0）需要仔细理解
- 信号处理的并发性很微妙——信号可能在任何时刻到达
- 僵尸进程的概念需要结合代码理解

## 与 Flutter/Dart 的关联

- **Dart 的 Isolate**：Isolate 本质上是一个轻量级进程。和 OS 进程一样，Isolate 有自己独立的内存空间，不共享状态。但 Isolate 比 OS 进程轻量得多，创建成本更低。
- **Isolate 之间的通信**：Dart 的 SendPort/ReceivePort 机制类似于进程间的信号/管道通信。
- **Flutter 的错误处理**：Flutter 的 `FlutterError.onError` 和 `runZonedGuarded` 本质上是"捕获异常"的机制，和 Unix 信号处理的思想类似——你在全局注册一个处理器，异常发生时自动调用。
- **热重载与进程**：`flutter run` 的热重载通过向运行中的 Dart VM 发送指令实现，这和向进程发送信号在概念上是相似的。

## 关键术语对照

| 英文 | 中文 | 一句话解释 |
|------|------|-----------|
| exception | 异常 | CPU 响应系统事件的机制 |
| interrupt | 中断 | 来自外部设备的事件信号 |
| trap | 陷阱 | 有意的异常（系统调用） |
| fault | 故障 | 可能可恢复的错误 |
| abort | 终止 | 不可恢复的致命错误 |
| process | 进程 | 执行中程序的实例 |
| context switch | 上下文切换 | CPU 从一个进程切换到另一个 |
| syscall | 系统调用 | 程序请求内核服务 |
| fork | fork | 创建子进程 |
| zombie | 僵尸进程 | 已终止但未被父进程回收的进程 |
| signal | 信号 | OS 向进程发送的异步通知 |
| kill | kill | 发送信号（不只是杀死进程） |
