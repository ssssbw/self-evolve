# 理财与认知路线重构及文档一致性审计设计

## 背景

当前理财和认知路线把一本书压缩为一周，与每周各只有一次学习时间的实际节奏不符。两份路线还存在阶段定义和执行表互相冲突、同一本书跨领域重复、旧的 100 天计划继续提供相反指令等问题。

本次调整以当前第一五年计划为约束：理财首先服务于现金流、本金积累和长期配置；认知首先服务于学习执行、逻辑判断和现实决策。路线只规定先后关系，不规定完成日期。

## 目标

- 将理财和认知路线改为“按顺序学习 + 实践产出 + 通关条件”。
- 每个领域同时只推进一本主线书，每周继续上次进度。
- 理财先完成财务底盘和长期投资基础，财报及主动选股后置。
- 认知按学习执行、逻辑、统计、心理、决策、博弈、制度逐层推进。
- 消除两条路线之间的书籍重复和阶段冲突。
- 识别并处理仍会误导当前执行的过时文档，同时保留历史记录。

## 非目标

- 不为任何书设置周数、页数或截止日期。
- 不扩大书单，不为每本书创建独立笔记文件。
- 不重写历史会话日志和已经发生的周复盘。
- 不在本次重构中调整技术学习的具体内容。

## 路线结构

### 理财

1. 财务底盘：资产、负债、现金流、备用金。
2. 财富行为：《金钱心理学》。
3. 长期投资：《漫步华尔街》到《股市长线法宝》。
4. 经济金融基础：《小岛经济学》到《金融的逻辑》。
5. 基础财报：《手把手教你读财报》到《从报表看企业》。
6. 投资决策：《穷查理宝典》到《聪明的投资者》。
7. 路线分支：长期配置者形成个人投资政策后暂停扩展；确定需要主动研究个股时，再按《股市真规则》《怎样选择成长股》《财务报表分析》《财务报表分析与证券估值》《故事与估值》的顺序深入。
8. 宏观选修：《货币金融学》到《债务危机》再到《风险-收益分析》，不作为长期配置路线的必修前置条件。

《纳瓦尔宝典》保留为选读，不承担金融知识主线职责。《置身事内》只放入认知路线。

### 认知

1. 学习与执行：《刻意练习》到《心流》再到《卓有成效的管理者》。
2. 逻辑与批判思维：《简单的逻辑学》到《学会提问》。
3. 数据判断：《统计会犯错》。
4. 心理与偏差：《思考，快与慢》到《影响力》。
5. 决策与不确定性：《原则》到《反脆弱》。
6. 博弈与权力：《博弈与社会》到《什么是权力》再到《硬球》。
7. 制度与现实：《置身事内》到《大败局》再到《洛克菲勒传》。
8. 历史与政治经济学：现有长期书单按兴趣逐本推进，不作为近期任务。

## 单阶段格式

每个阶段统一记录：学习目标、顺序资源、必做实践和通关条件。通关依据是能否产出并解释，不以读完页数作为唯一标准。允许跳过重复章节，也允许在确认边际收益过低后停止一本书。

## 审计结论

当前明确存在六类问题：理财路线阶段互相冲突、认知路线同样把进阶书提前、100 天计划与现行书单正面冲突、领域索引状态过时、旧日历和示例缺少历史标识、AI 上下文包含错误路径和不存在的目录。历史日志本身不是冲突来源，问题在于部分执行型文档没有声明自己已失效。
