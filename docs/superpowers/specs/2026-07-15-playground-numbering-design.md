# Playground 题目编号统一设计

## 背景

当前 `5-Playground/` 已经改为按“项目 -> 轨道或阶段/书本 -> 题型”组织，但题目文件仍沿用迁移前的全局编号，导致同一目录下出现跳号，例如 `001、003、005、007`。这会让人误判题目缺失，也增加后续新增题目时的维护成本。

## 目标

- 将每个叶子目录下的题目编号独立连续化。
- 保持现有目录结构不变，只调整文件名、题内标题和必要引用。
- 让历史入口文档在引用题目时仍然可读，不产生断链。

## 规则

1. 每个 `homework/`、`discussions/`、`challenges/` 目录各自从 `001` 开始连续编号。
2. 编号只在同一叶子目录内有意义，不再跨项目、跨轨道或跨题型全局唯一。
3. 历史或汇总文档如果同时引用多个轨道的题目，必须带上轨道名，例如“CSAPP 作业 #002”“设计模式讨论题 #001”。

## 变更范围

- 重命名 `5-Playground/` 下受影响的题目文件。
- 更新题目正文中的标题编号与 `answer.md` 自引用。
- 更新 `0-Projects/P001-基础重建/first-month-calendar.md` 中的题目编号和路径。
- 更新 `docs/superpowers/plans/2026-07-15-project-scoped-playground.md`，使其描述与现状一致。

## 非目标

- 不改动题目内容本身。
- 不新增或删除任何题目。
- 不调整项目、轨道、阶段或书本目录。

## 验证

- `find 5-Playground -type f | sort` 中各叶子目录的编号连续。
- `rg` 复查题目标题、`answer.md` 引用和旧路径，确认没有残留旧编号。
- `git diff --check` 通过。
