# Challenge 001 — Self-Evolve 知识库后台页面

## 目标

验证 L2 Web 全栈产品能力：Next.js、FastAPI、列表、筛选、详情页、加载状态、空状态和错误状态。

## 任务

基于 L1 的笔记元数据 API，实现一个知识库后台页面。

必须包含：

- 笔记列表。
- 按项目/领域、标签、是否已索引筛选。
- 笔记详情区域，展示路径、标题、摘要和元数据。
- 加载、空状态和错误状态。
- 前端请求后端 API，不把数据写死在页面里。

## 手写要求

- 先自己设计页面结构、接口调用和状态处理。
- AI 可以 review 交互和代码，不直接生成整页实现照抄。

## 验收

- 能从浏览器完成筛选和查看详情。
- 能讲清一次请求如何从 Next.js 到 FastAPI 再到 PostgreSQL。
- 能说明分页、筛选和错误处理的设计取舍。
- 能说明这个后台页面后续如何支撑 RAG 管理。
