# Challenge 004 — 知识点 2 分钟表达

## 目标

没有项目可讲时，训练技术知识点表达。重点不是背定义，而是能讲清原理、场景、取舍和项目应用。

## 任务

选择一个知识点，计时录音并转写，目标控制在 2 分钟内。

推荐题目：

- Structured Output 为什么比普通 JSON Prompt 更可靠？
- SSE 和 WebSocket 有什么区别，AI 流式输出为什么常用 SSE？
- RAG 解决什么问题，不能解决什么问题？
- Token、Context Window 和成本之间是什么关系？
- Embedding 和关键词搜索有什么区别？
- 为什么真实 AI 产品需要 Evaluation？

回答结构：

```text
一句话定义 -> 解决什么问题 -> 核心原理 -> 适用场景 -> 项目中怎么用 -> 常见坑
```

## 验收

- 2 分钟内讲完。
- 不只是背概念，必须有适用场景和取舍。
- 至少能回答 2 个追问。
- 能联系到 P004 或公司 AI 项目。
