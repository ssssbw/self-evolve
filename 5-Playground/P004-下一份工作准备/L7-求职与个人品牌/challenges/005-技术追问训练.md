# Challenge 005 — 技术追问训练

## 目标

训练面试中的连续追问能力，避免第一层回答能说，第二层就露怯。

## 任务

选择一个项目点或知识点，连续回答 3-5 个追问。

示例：

```text
问题：你为什么使用 Structured Output？
追问 1：它和普通 JSON Prompt 的差别是什么？
追问 2：如果模型仍然返回非法格式怎么办？
追问 3：怎么设计 schema？
追问 4：如何评估输出是否准确？
追问 5：成本和延迟怎么控制？
```

## 验收

- 每个追问都能给出具体回答。
- 回答中包含项目场景或工程取舍。
- 能区分“知道概念”和“能落地解决问题”。
- 记录至少 1 个需要补课的漏洞。

## 复盘

- 第几个追问开始卡住：
- 卡住原因：
- 需要补的知识：
- 下次复练题目：
