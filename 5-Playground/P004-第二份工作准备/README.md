# P004 — 第二份工作准备

本项目的互动内容以 challenge 为主，用来验收 AI 全栈能力金字塔和当前公司 AI 项目中的真实能力。

## 长期主 challenge

P004 的长期主 challenge 是 **Self-Evolve AI 助手**：围绕个人 Markdown 知识库构建一个 AI 全栈工作台。每一层 challenge 尽量在同一个项目上迭代，而不是做互不相关的小练习。

目标效果：

- L1：Markdown 笔记元数据 API。
- L2：Web 管理后台、目录浏览和搜索。
- L3：LLM 总结、问答和结构化输出。
- L4：RAG 知识库问答、引用来源和无答案拒答。
- L5：评测集、引用准确率、Token 成本和日志。
- L6：Flutter 移动端助手或 Go 网关 / 实时通信模块。
- L7：README、架构图、演示稿和面试表达。

当前公司用户反馈评估系统作为现实职业资产并行推进，但不使用公司数据做个人 challenge。

## 验收原则

- 不以“看过教程”作为完成标准。
- 每个关键能力点通过一个小 challenge 验收。
- challenge 结果要能回填到 P004 的职业资产、项目复盘或面试表达。
- 公司项目优先，金字塔补位；现实项目暴露什么缺口，就优先完成对应 challenge。
- challenge 的核心设计、代码、复盘和表达必须手写；AI 只能用于解释、提示、review 和追问。
