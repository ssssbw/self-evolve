# L1 知识验收测试

本目录用于保存 P004 L1 工程基础底座的知识验收测试。每份测试既是学习笔记入口，也是自测题和复盘记录。

## 使用规则

- 先独立作答，再查资料修正。
- 不直接让 AI 生成最终答案照抄。
- AI 可以用于解释概念、追问薄弱点、review 手写答案和补充反例。
- 每次作答后记录掌握度：20%、40%、60%、80% 或 100%。
- 达到 80% 才算当前知识点可用于项目；达到 100% 才算面试级表达。

## 建议作答流程

1. 用 25-45 分钟独立完成第一轮，不查答案。
2. 标出不确定题目，再查 MDN、RFC、框架文档或课程资料。
3. 用自己的话重写答案，不复制资料原文。
4. 提交手写答案给 AI 做 review。
5. 根据 review 修改后，更新掌握度和复盘。
