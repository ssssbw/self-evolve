# L7 — 求职与个人品牌

## 目标

验证技术能力是否已经转化成简历、项目表达、知识点表达和面试材料。

## 训练方式

L7 不只练项目表达。平时没有项目可讲时，也要练知识点表达。项目表达证明“做过什么”，知识点表达证明“是否真懂”。

每周至少完成 1 次表达训练：

1. 选题：项目题、知识点题、技术追问题或行为面试题。
2. 计时：先录 2 分钟版本，再根据需要压缩到 30 秒或扩展到 15 分钟。
3. 转写：把录音转成文字，不需要修饰。
4. 复盘：从结构、证据、技术准确性、表达清晰度和追问风险五个维度检查。
5. 重录：根据反馈重录一版。

## 题目类型

| 类型 | 训练目的 | 示例 |
| ---- | -------- | ---- |
| 项目表达 | 证明做过什么、解决什么问题 | 2 分钟介绍用户反馈评估系统 |
| 知识点表达 | 证明概念理解和技术判断 | Structured Output 为什么比普通 JSON Prompt 更可靠 |
| 技术追问 | 训练压力下的深入解释 | 模型输出错误时怎么兜底 |
| 行为面试 | 训练工作方式和沟通表达 | 加班压力下如何保证交付和成长 |
| 复盘改写 | 把口语回答改成面试答案 | 将转写稿改成 2 分钟结构化回答 |
