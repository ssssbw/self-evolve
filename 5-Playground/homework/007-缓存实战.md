## 题目一（必做）

**解释为什么遍历二维数组时"行优先"比"列优先"快：**

```c
// 行优先（快）
for (i = 0; i < N; i++)
    for (j = 0; j < N; j++)
        sum += array[i][j];

// 列优先（慢）
for (j = 0; j < N; j++)
    for (i = 0; i < N; i++)
        sum += array[i][j];
```

要求：
- 用缓存行的概念解释
- 用空间局部性的概念解释
- 假设缓存行大小 64 字节、int 占 4 字节，计算行优先和列优先的缓存命中率差异
