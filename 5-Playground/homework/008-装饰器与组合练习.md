# 作业 #008 — 装饰器与组合练习

> 前置阅读：Refactoring.Guru「装饰器模式」+「组合模式」

---

## 题目一（必做）

**用装饰器模式实现一个咖啡订单系统：**

要求：
- 基础咖啡 `Coffee` 接口：`cost()` 和 `description()`
- 基础饮品：`Espresso`（15元）、`HouseBlend`（12元）
- 装饰器：`Milk`（+3元）、`Mocha`（+4元）、`Whip`（+2元）
- 可以无限嵌套装饰器
- 用 Dart 实现

例子：`Whip(Mocha(Milk(Espresso())))` → "Espresso, Milk, Mocha, Whip" → 24 元

---

## 题目二（必做）

**用组合模式实现一个文件系统：**

要求：
- 组件接口 `FileComponent`：`name()` 和 `size()`
- 叶子 `File`：有名字和大小
- 容器 `Folder`：有名字，可包含 File 和 Folder
- `Folder.size()` 返回所有子元素大小之和
- 用 Go 实现（练习 Go 的接口和组合）

## 题目三（选做）

**Flutter 的 Widget 树是组合模式的体现吗？Container 是装饰器吗？**

要求：
- 用组合模式的定义分析 Widget 树
- 分析 Container 是不是装饰器（它做了什么？包装 child + 添加行为？）
- 给出你的结论和理由
