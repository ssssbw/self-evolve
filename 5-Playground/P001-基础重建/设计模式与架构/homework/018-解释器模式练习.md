# 作业 #018 — 解释器模式练习

> 前置阅读：Refactoring.Guru「解释器模式」  
> 建议语言：Dart  
> 目标：理解如何为简单语言或规则表达式建立解释执行结构。

## 题目一（必做）：简单筛选规则解释器

实现一个任务筛选规则。

支持表达式：

```text
status = done
priority = high
status = todo AND priority = high
status = done OR priority = low
```

要求：

- 定义表达式接口 `Expression`。
- 实现终结表达式：`StatusExpression`、`PriorityExpression`。
- 实现非终结表达式：`AndExpression`、`OrExpression`。
- 输入一个 `Task`，返回是否匹配。

思考：

- 解释器模式适合什么规模的语法？
- 如果规则越来越复杂，为什么可能需要 parser 或规则引擎？
- 解释器和策略模式有什么区别？

## 题目二（选做）：表单校验 DSL

设计一个很小的校验表达式：

```text
required AND minLength(6)
```

说明如何解析并执行。
