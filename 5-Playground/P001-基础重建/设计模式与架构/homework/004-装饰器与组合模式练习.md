# 作业 #004 — 装饰器与组合模式练习

> 前置阅读：Refactoring.Guru「装饰器模式」+「组合模式」  
> 建议语言：Dart  
> 目标：理解“动态叠加职责”和“树形整体-部分结构”的区别。

## 题目一（必做）：装饰器实现请求中间件

实现一个简单 API Client 装饰器系统。

要求：

- 定义 `HttpClient` 接口，包含 `send(Request request)`。
- 实现基础 `BaseHttpClient`。
- 实现装饰器：`LoggingClient`、`AuthClient`、`RetryClient`。
- 支持组合：`RetryClient(AuthClient(LoggingClient(BaseHttpClient())))`。

思考：

- 装饰器和继承相比解决了什么问题？
- 装饰器顺序会不会影响结果？举例说明。
- Flutter 中哪些 Widget 写法接近装饰器思想？

## 题目二（必做）：组合模式实现文件树

实现一个文件系统树。

要求：

- 定义 `FileComponent`，包含 `name`、`size()`、`printTree()`。
- 实现叶子节点 `FileNode`。
- 实现容器节点 `FolderNode`，能包含 File 和 Folder。
- `FolderNode.size()` 返回所有子节点大小之和。

思考：

- 为什么组合模式适合树形结构？
- 组合模式如何让客户端统一处理 File 和 Folder？
- Flutter Widget 树是否可以看作组合模式？为什么？

## 题目三（选做）：Container 是装饰器吗？

分析 Flutter 的 `Container`。

要求：

- 它包装 child 后增加了哪些能力？
- 它和典型装饰器有什么相似和不同？
- 给出你的结论。
