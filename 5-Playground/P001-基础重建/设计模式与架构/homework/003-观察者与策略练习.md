# 作业 #003 — 观察者与策略练习

## 题目一（必做）

**不使用任何状态管理库，用纯 Dart 实现一个简易版 ChangeNotifier + ValueNotifier：**

要求：
- 实现 `MyNotifier`（管理监听者列表、通知方法）
- 实现 `MyValueNotifier<T>`（持有值、值变化时通知）
- 写一个简单的测试：创建 notifier，注册两个监听者，修改值，验证两个监听者都收到了通知
- 不依赖 Flutter SDK

---

## 题目二（必做）

**用策略模式实现一个排序器：**

要求：
- 定义 `SortStrategy` 接口
- 实现三种策略：BubbleSort、QuickSort、MergeSort
- 写一个 `Sorter` 类，接受策略，对列表排序
- 运行时可以切换策略
- 用 Dart 实现

思考题：为什么不用 if-else 判断排序类型？策略模式比 if-else 好在哪里？

## 题目三（选做）

**分析 Provider/Riverpod 是如何基于观察者模式构建的：**

要求：
- 画出 Provider 的数据流图（Widget → Provider → Model → notifyListeners → Widget rebuild）
- 解释 `context.watch<T>()` 和 `context.read<T>()` 在观察者模式中分别扮演什么角色
- 为什么 `watch` 能让 Widget 在数据变化时自动 rebuild？
