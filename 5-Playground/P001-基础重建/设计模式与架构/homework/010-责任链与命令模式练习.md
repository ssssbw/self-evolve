# 作业 #010 — 责任链与命令模式练习

> 前置阅读：Refactoring.Guru「责任链模式」+「命令模式」  
> 建议语言：Dart  
> 目标：理解请求处理链和操作封装的差别。

## 题目一（必做）：责任链实现请求校验

实现一个 API 请求校验链。

处理器包括：

- `AuthHandler`
- `RateLimitHandler`
- `PermissionHandler`
- `BusinessValidationHandler`

要求：

- 每个 Handler 只处理一个校验点。
- 校验失败时停止向后传递。
- 校验通过时交给下一个 Handler。

思考：

- 责任链适合什么类型的流程？
- Handler 顺序为什么重要？
- 如果用一个大函数写所有校验，有什么问题？

## 题目二（必做）：命令模式实现撤销操作

实现一个文本编辑器命令系统。

要求：

- 定义 `Command`，包含 `execute()` 和 `undo()`。
- 实现 `InsertTextCommand`、`DeleteTextCommand`。
- `EditorInvoker` 保存命令历史。
- 支持撤销上一步操作。

思考：

- 命令模式把什么封装成了对象？
- 命令模式如何支持撤销、队列、日志或重试？
- 命令模式和策略模式有什么区别？
