# 作业 #005 — 适配器模式练习

> 前置阅读：Refactoring.Guru「适配器模式」  
> 建议语言：Dart  
> 目标：理解如何把不兼容接口转换成当前系统需要的接口。

## 题目一（必做）：适配第三方支付接口

业务中已有统一支付接口：

```text
PaymentGateway.pay(amount, orderId)
```

现在接入第三方 SDK，它只提供：

```text
ThirdPartyPay.charge(cents, tradeNo)
```

要求：

- 定义统一 `PaymentGateway` 接口。
- 模拟 `ThirdPartyPay`。
- 实现 `ThirdPartyPaymentAdapter`。
- 客户端只依赖 `PaymentGateway`。

思考：

- Adapter 解决了什么“不兼容”？
- 如果以后接入第二个第三方支付，结构如何扩展？
- 适配器和外观模式有什么区别？

## 题目二（必做）：适配旧项目数据模型

旧接口返回：

```text
user_name
avatar_url
vip_level
```

新页面需要：

```text
name
avatar
membership
```

要求：

- 定义新页面使用的 `UserProfile`。
- 实现一个 adapter 把旧模型转换成新模型。
- 处理字段缺失或空值。

## 题目三（选做）：Flutter 场景分析

找一个你工作中“接口不一致但不能改对方代码”的场景，说明如何用 Adapter 隔离变化。
