## 题目一（必做）

**以下是一段 C 函数和对应的 x86-64 汇编，请逐行注释：**

```c
int add_and_double(int a, int b) {
    int sum = a + b;
    return sum * 2;
}
```

```asm
add_and_double:
    pushq   %rbp
    movq    %rsp, %rbp
    movl    %edi, -4(%rbp)
    movl    %esi, -8(%rbp)
    movl    -4(%rbp), %eax
    addl    -8(%rbp), %eax
    movl    %eax, -12(%rbp)
    movl    -12(%rbp), %eax
    addl    %eax, %eax
    popq    %rbp
    ret
```

要求：每一行汇编都要注释它在做什么，包括：
- 为什么 push %rbp
- %edi 和 %esi 分别是什么
- -4(%rbp) 是什么意思
- 为什么最后 addl %eax, %eax（而不是 imull）

**解释以下问题：**

1. 为什么 x86-64 函数参数超过 6 个时要使用栈传递？前 6 个参数通过哪些寄存器传递？
2. 为什么函数返回值放在 %rax 中？调用者怎么知道去那里取？
