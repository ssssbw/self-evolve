# 作业 #002 — 整数的秘密

> 前置阅读：CSAPP 第 2 章 P67-P120

---

## 题目一（必做）

**用笔算出以下十六进制数的二进制和补码十进制值：**

1. 0xFF（8 位）
2. 0x80000000（32 位）
3. 0x7FFFFFFF（32 位）
4. 0xFFFFFFFF（32 位）

要求：写出完整的计算过程，不是只写答案。

---

## 题目二（必做）

**解释为什么 int 最大值是 2147483647（2^31 - 1）。**

要求：
- 从补码的定义出发推导
- 解释为什么不是 2^31（为什么 -1）
- 解释为什么负数最小值的绝对值比正数最大值大 1

---

## 题目三（必做）

**用 Dart 写一个函数，检测 32 位整数加法是否会溢出：**

要求：
- 不使用 try-catch
- 不使用 Dart 的任意精度特性
- 只用位运算和比较
- 解释你的检测逻辑为什么正确

提示：想想溢出时，两个正数相加结果变成负数（或两个负数相加结果变成正数）。

---

## 题目四（选做）

**研究 Dart 的 int 在不同平台上的行为差异：**

- Dart VM（移动端）中 int 是 64 位
- dart2js（Flutter Web）中 int 是 JavaScript number

写一段 Dart 代码，展示在两个平台上行为不同的整数运算，并解释原因。
